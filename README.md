# Kate Shea Ceramics Reference Library

This repo contains canonical references for generating Kate Shea Ceramics imagery.

Use the Skill for behaviour rules.
Use the Reference Map for image-specific constraints.

The `Example Post` images are not moodboard references. They are ground-truth examples for scale, composition, product realism, model fit, packaging dimensions, ceramic depth, and process imagery.

The `Character Sheets` folder contains the only approved models.

Do not generate images until the relevant reference files have been mapped.
