# Kate Shea Ceramics Canonical Image References

This repository is the canonical reference library for generating Kate Shea Ceramics product, model, collection, packaging, and process imagery.

These images are **not moodboard references**.

They are production references that lock important details such as:

- product scale
- artwork fidelity
- ceramic depth
- packaging dimensions
- hand-to-earring scale
- model earring scale
- approved model identity
- approved still-life styling
- artist/process hand reference

When using these references in Perplexity Computer or any image-generation workflow, treat them as **accuracy anchors**, not loose inspiration.

## Core Rule

The generated images must remain faithful to the real jewellery.

Preserve the exact:

- painted artwork
- ceramic shape
- ceramic depth
- scale
- colour relationships
- visible hardware
- handmade texture
- brushwork character
- product construction

Do not reinterpret, beautify, simplify, repaint, resize, or redesign the jewellery.

---

## Character Sheets

The `Character Sheets` folder contains the only approved model identities.

Use these for:

- `01_editorial_model.png`
- `08_close_on_ear.png`
- any other model-worn image

Rules:

- Use only the approved models from this folder.
- Choose one approved model for a product campaign or 10-image post set.
- Use the same model consistently across all model-worn images in that set.
- Do not invent a new model.
- Do not blend features from multiple character sheets.
- Do not switch models mid-campaign unless explicitly requested.

## Front/Back Matched Collection Workflow

When supplying front and back group shots:

1. Photograph or provide the front layout.
2. Turn the earrings over while keeping them in the same positions.
3. Photograph or provide the back layout.
4. Treat the front and back images as a linked reference pair.

Rules:

- Preserve the same item count.
- Preserve the same row structure.
- Preserve the same left-to-right order.
- Preserve approximate spacing and rotation.
- Match each back to its corresponding front position.
- Do not recompose the arrangement from scratch.
- Do not make a prettier but different layout.

The back-view image should feel like the same layout has simply been turned over in place.

---

## Group-Shot Pair Extraction Workflow

When a single group shot contains multiple pairs and the task is to create a 10-image post set for each pair:

1. Detect each pair in the group shot.
2. Build a stable extraction map.
3. Process pairs in reading order:
   - top row, left to right
   - then the next row, left to right
   - and so on
4. Treat each pair as its own product identity.
5. Generate the 10-image campaign for each pair using the canonical references above.

Rules:

- Do not merge neighbouring pairs.
- Do not swap matching partners.
- Do not let visual traits from one pair contaminate another pair.
- Do not invent missing product details.
- If a matching back-group image exists, use the same extraction map to match fronts to backs.

## Common Failure Modes to Avoid

The following failures must be explicitly avoided:

- Brushwork detail shot not matching `03_brushwork_detail.png`
- Box presentation with incorrect box size or proportions
- Group shot with inconsistent earring sizes
- Main pair made disproportionately large in a group shot
- Model-worn earring not matching the supplied product image
- Group shot containing foliage when not requested
- Artist/process image using generic hands instead of Kate’s hands
- Artist/process image changing the setting away from the canonical process reference
- Model not found in the approved character sheets
- Artwork being repainted, beautified, simplified, or subtly rewritten
- Hardware being invented or changed
- Ceramic depth being inaccurate

If any of these occur, the image fails QA and must be regenerated.

## Preflight Reference Mapping

Before generating a 10-image set, create a reference map.

For each image type, identify:

1. the exact canonical file being used
2. what physical or visual constraint it locks
3. what must not change

Do not generate images until this mapping is complete.

If a reference is missing or unclear, state which reference is missing instead of improvising.

## 10-Image Post Set

For each product campaign, generate the following image types unless instructed otherwise:

1. Editorial model shot
2. Clean flat lay of the pair
3. Close-up detail of brushwork
4. Scale shot in hand
5. Back of earring / hardware
6. Side angle showing ceramic depth
7. In-box presentation
8. Another model crop, closer on ear
9. A group shot showing the collection
10. Artist/process image

The full set should feel like one cohesive premium campaign while preserving exact product truth in every image.
